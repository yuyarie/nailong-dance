# 奶娃街舞 · 本地纯前端版

项目位置：`C:\Users\kxmu3\Desktop\WorkSpace\nailong-dance-local`

## 启动

需要 Node.js 20 或更新版本，此电脑已安装。

```powershell
cd C:\Users\kxmu3\Desktop\WorkSpace\nailong-dance-local
npm start
```

也可以双击 `start.cmd`。打开 http://127.0.0.1:5173 ，点击“开跳”。
停止服务：在启动窗口按 Ctrl+C。修改文件后刷新浏览器即可。
端口被占用时设置环境变量 PORT 后启动。

不需要 npm install，没有运行时 npm 依赖。请通过本地 HTTP 服务启动，直接双击 index.html 的 file:// 模式不支持 ES 模块和模型加载。
server.mjs 只提供静态文件，不包含游戏后端或 API，默认仅监听本机 127.0.0.1。

## 手机访问

电脑与手机在同一热点网络时，先停止已运行的服务，然后在 PowerShell 中启动：

```powershell
cd C:\Users\kxmu3\Desktop\WorkSpace\nailong-dance-local
$env:HOST = "0.0.0.0"
npm start
```

在手机浏览器打开 http://电脑的Wi-Fi IPv4地址:5173/ 。当前电脑地址可用 ipconfig 查看；热点重连后可能变化。如果 Windows 防火墙弹窗，允许 Node.js 在当前热点网络通信。手机热点可能限制手机访问连接设备，无法连接时可尝试让两台设备连接同一个路由器。

恢复仅本机监听：停止服务后执行 Remove-Item Env:HOST -ErrorAction SilentlyContinue，再 npm start。

## 结算判定与偏移推荐

判定时间轴按 key1–key4 分行显示，说明位于图外，包含预备时间及歌曲首尾判定。非 Autoplay 结算会统计点按与长条起点的平均击打误差（至少 10 次有效击打，Miss 不参与）：推荐偏移 = 本局使用的偏移 + 平均误差，晚按增加、早按减少，按 10ms 四舍五入并限制在 ±1000ms。玩家点击使用后才保存，自动演示不显示推荐框。推荐仅供参考，受玩家击打习惯影响。

## 音符提示

四轨音符头、箭头与长条宽度为原尺寸的 1.5 倍，保持音符中心与判定线对齐。同一时刻的双押、三押和四押使用横向白色连线连接参与轨道，长条只连接起点；判定后连线更新或消失。设置中可开关多押提示连接线，默认开启，选择自动保存并在下次演出生效。按键及 Perfect / Good / Miss 判定音效已移除，没有开启入口；菜单操作音效保留。

## Autoplay

歌曲详情右侧可开启 Autoplay 自动演示（手机窄屏时换行显示）。默认关闭，仅本次页面会话保留开关；自动处理点按和长条，支持暂停、继续和重开。演出及结算标明自动演示，不计入本机成绩、累计统计、成就或奶币。

## 导入谱面

在“开跳”点击“导入谱面”，同时选中一个或多个 .mc 和对应的音乐文件（按住 Ctrl 多选）。音乐文件名必须匹配谱面里的 sound 名称。支持 Key 模式、四列轨道，保留原谱面给出的版本/难度描述；不会按难度重新生成音符。音乐支持浏览器可解码的 ogg / mp3 / wav / m4a，单个音乐最大 50MB，单个谱面最大 10MB。

解析拍点 [整数拍, 分子, 分母] 与 BPM 时间轴，兼容旧谱面的未约分拍点及第五列 BGM 事件；preview 按毫秒读取；游戏时间为拍点对应秒数减去背景音乐事件拍点和 offset（毫秒）。长条跨 BPM 变化时分别计算首尾时间。谱面有负时间音符或开头太近时，会先留出预备时间再播放音乐。设置中的判定偏移用于设备校准，叠加在谱面时间上，Hi-Speed 只控制下落速度。

只导入谱面和一条配套背景音乐，不读取谱面背景图或播放单独的按键音效，打谱界面沿用现有外观。非 4Key 谱面、缺失音乐、无效拍点、同轨长条重叠或结尾超过音乐时长会提示错误。

旧自动谱面音乐和旧难度成绩不再出现在选曲/纪录页，原存档仍保留，装扮、奶币和累计进度继续使用。导入的谱面保存在当前浏览器和端口，清空站点数据会删除它们。

## 判定偏移测量

在设置的“判定偏移”下点击“测量判定偏移”。先听 4 拍，再跟着 120 BPM 的节拍按任一绑定键、空格，或点击“跟拍击打”，共测量 20 拍。背景音乐在测量期间静音，校准音不受音效开关影响。

至少需要 10 次稳定击打，使用中位数并剔除离群值；结果按 10ms 取整，点击“应用测量结果”后保存为绝对偏移，不叠加旧值。晚于节拍的输入对应正偏移。取消、离开设置、切后台或失去焦点时停止测量。

固定节拍通过最近拍匹配，单次接受范围为 ±240ms，不能区分偏差超过半拍的情况。结果包含玩家跟拍习惯和设备延迟，建议用实际游玩的耳机重复测量；更大的偏移可手动调节。

## 开发文件

- index.html / style.css：界面与样式。
- js/main.js：场景初始化、单人流程和输入。
- js/game.js：谱面、判定、计分与结算。
- js/dancer.js / js/fx.js / js/opening.js：舞者、特效和开场。
- js/ui.js：页面、涂装、成就、设置和本机存档。
- js/audio.js：背景音乐、音效和语音。
- js/malody.js / js/customstore.js：Malody 谱面解析、导入验证和 IndexedDB 存储。
- charts/library/、js/library.js：本地曲库素材和索引；只包含 4Key 谱面、配套音乐与每首歌的一张封面。
- tests/malody.test.mjs：谱面时间、变速、偏移、长条、预备时间和结算测试，运行 npm test。
- vendor/three/：本地 Three.js 与其 MIT 许可证。
- gifts/、sounds/、根目录模型与音频：原站素材。
